# 前端可视化数据看板验收记录

验收日期：2026-10-13  
适用页面：`/dashboards`

## 完成范围

- 看板库支持关键字搜索，以及全部、草稿、已发布和我创建的分类，并提供创建、查看、编辑和历史版本入口。
- 新建看板只能选择当前工作空间内已发布的图表版本，初始组件自动进入 12 列网格。
- 编辑器支持添加、移除、拖拽移动、方向键微调、加宽/缩窄、增高/降低，并将位置和尺寸自动保存到看板草稿。
- 支持时间范围、单选维度和多选维度全局筛选器；筛选定义、布局和固定图表版本一起进入不可变发布版本。
- 图表点击通过声明式 `interactionFieldId` 形成联动筛选，并重新请求 Spring Boot，不在浏览器内二次聚合。
- 下钻只展示当前成员本次查询已获授权的返回行，不额外请求未授权明细。
- 支持草稿预览、正式版切换、发布确认和历史版本查看；发布后只能通过新草稿继续修改。
- 手动刷新与 60/120/300 秒自动刷新可选；后台标签页暂停自动刷新，路由卸载或工作空间切换会取消旧请求。
- 每个组件维护独立 loading、success 和 error 状态；后端返回单图失败时，其余图表继续渲染，失败卡可重试。
- 小屏幕降级为单列看板，保留筛选、刷新和只读查看能力。

## 权限与一致性边界

- 正式看板每次通过统一查询服务执行固定的已发布图表查询计划，并重新应用查看者租户、工作空间、行级和列级权限。
- 草稿查询要求 `dashboard:manage`；普通查看者只能读取已发布版本和其有权访问的数据。
- 看板不能引用其他租户或工作空间的图表，正式发布只能引用已发布图表版本。
- 图表联动和全局筛选只传递强类型 QueryPlan 筛选，不接受 SQL 或任意脚本。
- 金额由后端查询结果原样进入组件；局部状态映射不转换业务值。角色验收使用 `129.50` 与 `79.25` 两个权限结果验证没有串用缓存或丢失精度。

## 验证结果

- `npm run ci`：通过，11 个测试文件、56 个测试全部通过。
- `npm run build`：通过；看板页面独立懒加载块约 24.91 kB，gzip 约 8.44 kB。
- 前端布局测试覆盖 12 列边界、移动、最小/最大尺寸、新组件位置、局部失败隔离和金额字符串保持。
- 后端 `checkstyle:check` 通过；看板闭环、角色权限数据隔离、金额一致性及图表规范定向测试 4 项通过。

ECharts 公共块仍有超过 500 kB 的非阻断构建提示；后续性能阶段可继续按图表类型拆包。真实生产角色矩阵仍应在接入实际 MySQL、权限策略和分析库数据后执行端到端复验。
