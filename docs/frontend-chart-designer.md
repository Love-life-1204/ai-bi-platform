# 前端图表设计器验收记录

验收日期：2026-10-13  
适用页面：`/charts`

## 完成范围

- 图表库支持按名称/编码、图表类型和发布状态筛选，并提供新建、编辑、校验、历史版本和发布入口。
- 设计器支持指标卡、柱状图、折线图、明细表、饼图、堆叠图和透视表七类组件。
- 数据来源仅允许当前工作空间内已发布的数据集版本和指标版本；维度来自选定数据集版本。
- 按图表类型构造最小查询维度：指标卡不带维度，普通坐标图只带分类维度，透视表固定行/列维度，明细表使用用户选择的明细维度。
- 支持分类/数值字段、排序、查询行数、图内标题、X/Y 轴标题、单位、数字格式、小数位、图例、标签和无数据文案配置。
- 参数变化 450 ms 后自动预览；新请求会取消旧请求，并用请求序列阻止乱序响应覆盖最新结果。
- 支持草稿创建和修改、服务端校验定位、发布确认、不可变发布版本和历史版本查看。

## 边界与安全

- 图表配置是声明式白名单，不接受 SQL、HTML、脚本、回调函数或任意 ECharts 配置。
- Spring Boot 校验图表类型、数据集版本、指标/维度绑定、透视表行列字段和 0–8 位精度；前端校验只用于即时反馈。
- 数值 `0` 保持为真实零值，非有限值和非数字异常显示为空缺，不伪造成零。
- 预览超过 1,000 行时均匀抽样并明确提示；保存的查询限制不受展示抽样影响。
- 单次查询失败仅显示在当前预览卡片并允许重试，不触发页面白屏或全局重复错误提示。
- 发布指标和前端菜单隐藏不构成授权；读取、创建、修改、查询和发布仍由 Spring Boot 做租户、工作空间及业务权限校验。
