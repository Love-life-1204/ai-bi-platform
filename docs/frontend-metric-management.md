# 前端指标管理验收记录

验收日期：2026-10-13  
适用页面：`/metrics`（兼容 `/semantic/metrics`）

## 完成范围

- 指标列表支持按关键字、来源数据集、发布状态和负责人筛选，显示单位、来源版本、公式摘要及状态。
- 四步创建/编辑向导覆盖指标身份与来源、受控公式、时间/币种/维度治理、确认与试算。
- 来源只能选择当前工作空间内已发布的数据集版本；字段选择来自该不可变版本。
- 公式通过白名单控件构建 `SUM`、`COUNT`、`COUNT_DISTINCT`、`AVG`、`MIN`、`MAX`、条件比较及 `ADD`、`SUB`、`DIV`、`NULLIF` AST，不提供 SQL 或任意函数文本输入。
- 时间范围固定为 `[start, end)`，支持 IANA 业务时区、业务时间字段、单币种/固定币种/跨币种模式、目标币种、批准汇率来源、0–8 位精度及允许下钻维度。
- 保存前执行本地结构校验；保存后调用 Spring Boot 公式、字段、时间、币种、依赖和循环依赖校验，问题可定位回向导步骤。
- 优先使用当前成员经过行列权限过滤的数据集预览行进行试算；没有实际样例时可使用明确标注的退款/取消、缺失值、零分母和跨币种沙盒场景。
- 跨币种样例没有后端批准汇率数据时不生成虚假结果；零分母显示“未定义”；缺失值展示受影响行数。
- 支持指标草稿更新、乐观锁、校验后发布、不可变历史版本及来源数据集、直接依赖、下游受影响指标提示。

## 安全与计算边界

- 前端公式构建器只生成受控 AST，Spring Boot 的算子白名单和版本校验仍是最终门禁。
- 指标试算请求数据集权限预览接口，不能绕过租户、工作空间、行级和列级权限。
- 沙盒数据仅验证口径边界，页面明确标识它不是实际业务结果。
- 跨币种换算需要后端提供批准汇率来源；前端不会自行编造汇率。
- 发布按钮、菜单隐藏和前端校验不构成真正授权，创建、修改、校验和发布仍由后端 `metric:manage` 权限控制。
