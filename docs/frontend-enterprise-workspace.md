# 企业工作台与组织管理前端说明

更新日期：2026-10-12

## 已完成页面

| 路由 | 页面 | 能力 |
|---|---|---|
| `/workspace` | 企业工作台 | 当前企业/工作空间摘要、授权销售额/订单量/客户量、最近看板、同步任务状态 |
| `/organization/company` | 企业信息 | 企业名称、默认时区、默认币种读取与乐观锁更新 |
| `/organization/members` | 组织与成员 | 部门树、企业成员、角色与有效状态、邀请成员、企业/工作空间范围角色分配 |

顶部栏同时提供企业和工作空间选择器。前端只展示活动工作空间，服务端仍负责最终资源权限校验。

## 指标与空状态

工作台不生成模拟经营数据。前端从当前工作空间的已授权指标中匹配销售额、订单量和客户量，通过已发布指标版本执行统一查询；没有配置或没有权限时显示“未配置或未获得指标权限”。看板、同步和指标任一区域失败时采用局部警告，其余区域继续可用。

## 安全切换

企业切换先使用全局令牌换取新的租户上下文，再装载该企业的活动工作空间。工作空间切换只允许选择当前接口返回的活动工作空间。切换成功后统一执行：

1. 取消仍在进行的普通 API 请求；
2. 删除 `aibi.cache.*`、`aibi.recentDashboards.*` 和 `aibi.ai.lastEvent.*` 浏览器状态；
3. 更新企业/工作空间标识并递增上下文版本；
4. 返回 `/workspace`，通过带上下文版本的路由组件 key 销毁并重建页面；
5. AI 页面卸载时取消 SSE，ECharts 组件随页面上下文一并卸载。

企业切换失败时恢复原企业令牌、成员和工作空间快照，不产生半切换状态。

## 后端契约补充
