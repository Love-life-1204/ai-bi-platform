开发要求：
1. 先检查现有项目代码，优先复用已经实现的功能，禁止无必要的重复开发。
2. 严格按照提供的任务编号逐步开发，每次只完成当前任务，不得擅自跨阶段开发。
3. 开发前先说明当前任务涉及哪些文件、数据库表、接口和依赖。
4. 后端按照 Controller → Service → ServiceImpl → Manager → Mapper → Entity 的分层规范组织代码。
5. 前后端分离，所有接口必须考虑多租户隔离、身份认证、权限控制、参数校验、统一异常处理。
6. 关键代码添加简洁中文注释，保持命名清晰，避免不必要的多层嵌套和重复代码。
7. 每完成一个功能，自动运行相关单元测试、接口测试和必要的集成测试。
8. 如果测试失败，应先分析原因并修复，不能通过删除测试、跳过权限检查等方式使测试通过。
9. 每一步完成后输出：修改的文件、实现的功能、测试命令、实际测试结果、遗留问题。
10. 未经实际执行的测试，不得标记为测试通过。
11. 当前任务通过验收后再进入下一项，保持 Git 提交粒度合理、随时可以回滚。
12. 优先保障数据正确性、租户隔离和系统稳定性，不为了开发速度降低安全标准。
