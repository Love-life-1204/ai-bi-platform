## 关键安全语义

- 所有租户上下文令牌绑定 `session_id`、`user_id`、`tenant_id`、`member_id`、租户权限版本和成员权限版本。
- 会话撤销、租户冻结、成员停用/移除或权限版本不一致时，上下文校验立即失败。
- RBAC 与资产 ACL 均执行显式 `DENY` 优先；ACL 支持成员、角色和部门主体。
- RLS 同组策略执行 OR、不同组执行 AND；已配置策略组但无匹配授权时生成拒绝全部条件。
- CLS 执行 `DENY > MASKED > VISIBLE`；字段已配置 CLS 但无匹配授权时默认 `DENY`。
- 异步任务保存授权快照，每次读取前重新校验活动会话、租户/成员状态、权限版本及实时 RBAC/ACL。
- 刷新令牌和邀请令牌仅保存 SHA-256 摘要；刷新令牌使用一次后撤销并轮换。

## 阶段验收结论

`MultiTenantPermissionStageAcceptanceTest` 验证：

1. 同一全局用户可以在两家租户间分别建立正确的权限上下文；
2. 相同数据集业务 ID 在不同租户内独立授权；
3. ALLOW 角色只能获得被授予的行级数据；
4. DENY 角色不能读取数据；
5. 使用甲租户令牌访问乙租户接口返回 403。

`TenantDataIsolationIntegrationTest` 进一步验证两家租户可使用相同工作空间编码和相同资产业务 ID，跨租户猜测资产主键返回 404，错误租户上下文返回 403。

`DisabledMemberAuthorizationIntegrationTest` 验证成员停用后旧令牌、再次切换企业和运行中的异步任务均不能继续读取数据。
