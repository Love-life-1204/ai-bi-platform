# 前端数据集管理验收记录

验收日期：2026-10-13  
适用页面：`/semantic`

## 完成范围

- 数据集列表显示名称、编码、来源表、当前版本、草稿提示、发布状态和更新时间，并支持工作空间隔离与搜索。
- 四步创建/编辑向导覆盖基本信息与来源表、字段语义配置、关联配置、复核保存。
- 来源表和字段直接读取数据源元数据；对象与字段使用后端持久化 ID，旧快照会在读取时补齐 ID。
- 字段支持业务名称、数据类型、维度/度量、敏感等级和展示格式。展示格式随不可变数据集版本保存。
- 关联配置支持目标已发布版本、左右关联键、基数、维表唯一性、审批状态和去重规则；本地即时提示多对多、非唯一维表和未审批关联，服务端校验仍为最终依据。
- 数据预览调用真实权限接口，展示策略命中、过滤前后行数、可见字段、脱敏值和权限拒绝状态，不生成伪造的“预览成功”数据。
- 校验结果展示服务端错误码、字段路径和提示；点击问题可回到字段或关联步骤定位。
- 支持保存草稿、乐观锁更新、校验后发布确认、发布冲突提示和历史版本查看。只有 `VALIDATED` 状态允许发布。
- 已发布数据集版本可作为其他数据集关联目标，并保留 `currentVersionId` 供后续指标模块引用。

## 异常场景

| 场景 | 处理方式 |
|---|---|
| 非法字段类型 | 前端即时校验并由后端返回 `UNSUPPORTED_FIELD_TYPE` |
| 字段/业务名称重复 | 前端定位到字段步骤，阻止保存 |
| 关联编码重复 | 前端即时校验，后端再次拒绝 |
| 未审批或多对多关联 | 显示高风险警告；服务端校验阻止发布 |
| 非唯一维表关联 | 要求确认唯一性或配置去重规则 |
| 发布并发冲突 | 使用 `lockVersion`；收到冲突后刷新列表并提示重新检查 |
| 数据权限不足 | 预览显示 Forbidden/错误状态；后端负责行过滤、列拒绝和脱敏 |

## 安全边界

前端的按钮禁用、路由隐藏和本地校验仅改善交互，不构成授权。工作空间访问、数据集修改、发布、行级过滤、列级拒绝与脱敏均必须由 Spring Boot 根据当前租户、成员和数据权限策略强制执行。
